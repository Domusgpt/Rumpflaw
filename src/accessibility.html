Accessibility

Effective November 6, 2026

{{ firm.name }} wants everyone to be able to use this website. We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.2 at Level AA.

What we’ve done

  • Motion you control. The site uses scroll-linked animation. If your device is set to reduce motion, all scroll animation, smooth scrolling and the opening sequence are turned off and the page scrolls normally.
  • Keyboard access. Every link, menu and form control can be reached and used with a keyboard, with a visible focus indicator and a “skip to main content” link.
  • Readable text. Body text meets WCAG AA contrast, scales with your browser’s text size, and the layout adapts to narrow screens and zoom.
  • Structure. Pages use meaningful headings and landmarks, and decorative graphics are hidden from screen readers. The service-area chart has a text description and the same towns are listed in text.
  • Forms. Every field has a visible label, and errors are described in text and announced to assistive technology.
  • Works without scripts. All content is in the page itself; if JavaScript is unavailable, content is shown without animation.
